# 本地配置示例

按实际环境填写以下非敏感信息，保存在仓库之外。不要填写 Cookie、密码或令牌。

- 源项目：https://github.com/DeppWang/youdaonote-pull
- 项目目录：`<项目绝对路径>`
- 项目 Python：`<项目目录>/.venv/bin/python`
- 导出目录：`<笔记导出目录>`，与项目和本技能目录分开。
- GitHub 账号与目标仓库：`<OWNER>/<PRIVATE_REPO>`，必须实时验证为私有仓库。
- GitHub CLI：使用 PATH 中的 `gh` 或已核实的本机路径。
- 独立运行目录：`<运行状态目录>`，不在导出目录或待推送仓库中。
- 最近成功的云端清单、原始导出快照、远端 SHA：在运行状态目录记录，每次使用重新核实。

首次部署没有历史基线时，不猜测旧路径、不清理未知文件。插件与 CLI 的身份可能不同，应核对实际使用通道。
